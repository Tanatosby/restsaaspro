"Para llevar" en un pedido manual

Hoy "Agregar manual" no tiene forma de marcar un pedido para llevar — todo pedido manual queda "en el local" sin excepción, aunque el mozo lo haya tomado por teléfono o de palabra para alguien que se lo lleva. El toggle ya existe en menu.html (el comensal), pero POST /api/orders (la ruta que usa Agregar manual) ni siquiera acepta el campo. Sin cambios de código todavía — esto es la propuesta para revisar antes de tocar nada.
